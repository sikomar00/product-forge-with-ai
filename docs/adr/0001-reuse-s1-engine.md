# S1 엔진을 새로 짜지 않고 가져와 패키지로 재구성한다

S1(`sailingstone-quest`)에는 이미 동작하는 엔진이 있다. `quest/engine.py`(962줄)가 학습 상태·XP·힌트 3단계·원샷 보너스·승급 시험·복습을 처리하고, 미션 52개(SQL 42개, Python 10개)가 이 엔진으로 돌아간다(2026-11-09 S1 코드 확인). 그래서 Product Forge 엔진은 이 로직을 가져와 `quest/` 패키지의 `core/`·`kinds/`·`checks/`로 나누고, 새 미션 유형(결정·감사·장애)과 체크 프리미티브를 더한다(design.md 8.1·8.2절).

## Considered Options
- 새로 작성: 구조는 깔끔해지지만, 이미 검증된 보상·힌트·복습 규칙을 다시 만들고 다시 시험해야 한다.
- S1을 그 자리에서 계속 확장: `engine.py` 한 파일이 이미 962줄로, 하네스 코드 규칙(`rules/code.md`, 파일 최대 500줄)을 넘는다.

## Consequences
- M0 완료 기준은 S1 미션 52개의 모범 답안 회귀 테스트 통과다(design.md 9절).
- S1의 Python 미션 10개는 pandas(DataFrame)로 풀고 채점한다. 엔진 본체는 표준 라이브러리 우선이므로, pandas를 S1 회귀 테스트용으로만 둘지 Plan에서 정한다.
- S1 저장소는 바꾸지 않는다. 필요한 코드는 이 리포로 복사해 고친다.
- 엔진 구역이므로 사용자가 AI와 바이브코딩한다(ADR-0006).
